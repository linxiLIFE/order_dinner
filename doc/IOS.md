# iOS / iPad 客户端

iOS 工程位于 `ios/App/App.xcodeproj`，应用标识为 `com.orderdinner.pos`，显示名称为「餐厅点单台」。支持 iOS / iPadOS 16 及以上，iPhone 与 iPad；iPad 支持横屏、竖屏及倒置竖屏，不锁定全屏。与网页版共用 `web/src` 的 React 页面、业务接口、权限、服务器草稿、打印队列和实时同步。

iOS 将网页源码构建到安装包，默认连接 `https://43.142.138.108:1316`。原生版本更新需要重建签名安装包；服务器业务数据保持共享。网页版与安卓继续使用现有部署方式。iOS 点菜界面使用网页版布局和预览左右切换；窄窗口自动上下排列。安全边距和可视窗口高度适配旋转、分屏、软键盘。中文字体只打入 iOS，避免系统字体回退异常，保留原有字号、颜色和布局。

报表导出通过原生分享菜单保存到「文件」或分享给其他应用，保留原始 CSV 内容。iPad 分享菜单设置了 popover 锚点。打印通过现有服务端队列和固定安卓蓝牙打印主机执行，流程与网页版相同；iOS 不承担安卓蓝牙打印主机角色。

## 构建

使用 Xcode 及其 iOS SDK；依赖使用 Swift Package Manager，无需 CocoaPods。首次使用运行 `npm install`。

```bash
# 模拟器应用及 zip
npm run package:ios
# 未签名设备归档，不能直接安装
npm run package:ios -- unsigned
# 开发签名归档与 IPA，填写自己的 Apple 团队编号
IOS_DEVELOPMENT_TEAM=你的团队编号 npm run package:ios -- archive
# 打开 Xcode 工程
npm run open:ios
```

输出位于 `release/ios/<版本>/<时间-进程编号>/`。使用 `ORDER_DINNER_URL=https://你的服务地址` 可以改变 API 服务地址。构建脚本采用独立输出目录；同步前旧的生成资源移到废纸篓。原生源文件已纳入版本库。

默认导出为开发签名 `debugging`，仅能安装到描述文件授权设备。个人免费团队签名会短期过期，不能等同于 App Store / TestFlight 发布。具有相应资格的开发者团队可以设置 `IOS_EXPORT_METHOD=app-store-connect` 等导出方法；本次没有上传应用。
