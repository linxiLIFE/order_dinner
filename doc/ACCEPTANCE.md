# 验收记录模板

## 已可验证的代码链路

- [ ] 登录与老板/收银员权限隔离
- [ ] 空桌开台、手机号顾客或散客、人数默认值
- [ ] 分类、菜品、中文名/拼音搜索，售价与成本快照
- [ ] 首次下单和加菜批次分别生成两份厨房打印任务
- [ ] 部分/全部赠送，赠送成本仍进入成本
- [ ] 未制作/已制作退菜，退菜单两份，损耗只计已制作部分
- [ ] 人工减免、目标实收换算、现金/微信/支付宝等收款方式
- [ ] 积分抵扣与获得在同一事务完成，积分不足被阻止
- [ ] 收款后桌台释放，小票任务一份，重复请求不重复记账
- [ ] 老板撤销重结、积分冲销、原订单与新订单留痕
- [ ] 顾客积分流水、消费记录、营业统计和 CSV 导出
- [ ] 打印任务领取、发送回执、失败/结果不明重试
- [ ] 断网时点餐草稿保留，恢复后刷新订单再提交

## 需要现场或真实环境确认

- [ ] 网页在电脑和手机真实浏览器布局
- [ ] Windows 10/11 x64 安装包安装、升级和卸载
- [ ] Android 8+ APK 安装、登录保持和应用重启恢复
- [ ] XP-N160II 蓝牙配对、RFCOMM 通道、中文、80 毫米纸
- [ ] 两份备菜单逐份出纸、缺纸、断链、结果不明、补打
- [ ] 两台设备并发开台/加菜/结账
- [ ] 真实线上域名证书、备份下载和恢复演练

每项记录时间、设备、测试账号、订单号、打印任务号和结果；“构建通过”不能替代实机或真实生产验收。
